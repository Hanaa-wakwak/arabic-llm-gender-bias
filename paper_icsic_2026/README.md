# ICSIC 2026 Conference Paper Draft

Paper title:

Measuring Occupational Gender Bias in Arabic Causal Language Models Using a Dialect-Aware Counterfactual Benchmark

Target venue:

6th International Computer Sciences and Informatics Conference (ICSIC 2026)

Main paper type:

Conference paper based on the thesis project, prepared as a shorter version than the planned Q1 journal paper.

Main contribution:

A dialect-aware Arabic occupational gender-bias benchmark and likelihood-based evaluation framework for Arabic causal language models.

Included components:

- Arabic occupational counterfactual benchmark
- MSA and Egyptian Arabic templates
- v2 main benchmark
- v4 template perturbation benchmark
- v5 job-title benchmark
- v6 expanded job-role benchmark
- ArabJobs v7 external benchmark
- likelihood-based score_difference metric
- model-family comparison
- template and dialect robustness analysis
- token-length control
- factor sensitivity analysis
- software-supported evaluation pipeline
- mitigation experiment summary

Important note:

This conference version should remain shorter than the future Q1 journal version. The Q1 version should include fuller human validation, more detailed robustness analysis, expanded related work, and a more complete mitigation discussion.
