## Main Empirical Result

The v2 benchmark remains the main validated benchmark.

It showed a statistically significant model-family pattern.

---

## Main Methodological Result

The v4 benchmark showed that measured Arabic occupational gender bias is highly sensitive to template formulation, semantic frame, and dialect.

The strongest practical effect was template ID.

---

## Final Claim

This thesis contributes a robustness-oriented Arabic occupational gender-bias evaluation suite, not only a single benchmark.

It shows that Arabic gender-bias evaluation is model-dependent and benchmark-design-dependent.
