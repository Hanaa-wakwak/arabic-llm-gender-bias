# v6 Expanded Job Roles and Departments Dataset Design

## Purpose

v6 expands the occupational benchmark from occupation-level pairs into a structured job-role benchmark.

## Added Dimensions

- department
- job_family
- role_key
- seniority_level
- workplace_context
- job_role_type
- masculine_job_title
- feminine_job_title

- Role types: 37
