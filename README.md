# Arabic LLM Gender Bias Thesis

## Working Title
Counterfactual and Intersectional Detection and Mitigation of Gender Bias in Arabic Large Language Models.

## Research Area
Arabic Natural Language Processing, Large Language Models, Fairness, Gender Bias, Dialectal Evaluation.

## Problem Statement
Arabic LLMs may encode gender bias in ways that English-centric benchmarks cannot properly capture because Arabic has grammatical gender agreement in verbs, nouns, adjectives, and pronouns.

## Initial Scope
This project starts with a small pilot benchmark before building the full benchmark.

### Languages / Dialects
- Modern Standard Arabic
- Egyptian Arabic

### Bias Dimensions
- Occupational gender stereotypes
- Trait and adjective stereotypes

### First Benchmark Format
- Counterfactual gender minimal pairs

### First Evaluation Goal
Measure whether an Arabic language model assigns different scores to masculine and feminine versions of the same sentence.

## First Practical Goal
Build a pilot dataset of 50 Arabic minimal pairs and run one baseline model evaluation.
