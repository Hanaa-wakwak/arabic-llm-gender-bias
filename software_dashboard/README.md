# Arabic Occupational Gender Bias Evaluation Dashboard

This dashboard supports the thesis project:

**Measuring Occupational Gender Bias in Arabic Causal Language Models using a Counterfactual Dialect-Aware Benchmark**

## Purpose

The dashboard provides a software interface for inspecting benchmark datasets, model results, validation outputs, and Q1-oriented robustness analyses.

## Main Features

- Dataset explorer for v2, v4, v5, v6, and ArabJobs v7
- Model result visualization
- Cross-benchmark comparison
- Validation and robustness dashboard
- Score-difference validation inspection
- Scoring command generator

## Main Score

```text
score_difference = masculine_score - feminine_score
